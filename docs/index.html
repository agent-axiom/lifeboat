THE SMALL PRINT, IN NORMAL TYPE

Good questions.

Is this a live integration with my issue tracker?

No. Lifeboat imports snapshots. Actions in your local app do not write back to GitHub, Jira, or Trello. Some source fields remain raw-only rather than becoming editable app fields.

Where does GPT-6 Astra fit in?

In Studio, Astra helps turn reviewed context and a workflow request into an inspectable contract. You accept the behavior before packaging. The downloaded Player executes supported actions locally, without calling the model for each action. The browser sample above uses a pre-generated workflow and makes no model calls.

Does my data leave my device?

The browser sample uses only fictional data and stores changes locally when browser storage is available. It does not upload issues. In Studio, the context you submit for AI design is sent to the model provider using your API access. Review that context before submitting. The public site is hosted by GitHub Pages; following external links or loading the optional Product Hunt badge contacts those services.

Is the preview free?

The preview downloads and browser sample are free. Designing new AI workflows requires your own API access, which can incur provider charges. The ready-made Player does not need a key.

Is the browser sample the full product?

No. It is a small, client-side illustration of reviewing and running a contract. It does not import your files, call Astra, generate applications, or implement the full Player runtime. Download Studio or Player to try those local workflows.
